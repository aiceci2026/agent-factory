Add an agent

One Markdown file in agents/<name>/agent.md. The frontmatter below is the whole contract — no vendor names, no model ids, so the definition survives a move to another runtime. Validate with python adapters/validate.py. 

---
name: my-new-agent
version: 1
purpose: One sentence on what it does for you.
status: scaffold
trigger:
  type: schedule        # manual | schedule | event
  cron: "0 9 * * 1-5"
  tz: Asia/Hong_Kong
inputs:  [mail.search, store.query]
outputs: [store.propose, run.log]
approval: required      # proposals only; never acts alone
model_hint:
  tier: default         # quick | default | complex
limits:
  lookback_days: 7
  max_proposals: 20
---
