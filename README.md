# Agent Factory — app shell

This repository holds a single HTML file: a user interface and nothing else.

It contains no data. No tasks, no names, no organisations, no numbers. The page is an
empty frame.

All content lives in a separate private repository and is loaded into this page at
runtime, only after the person using it supplies their own GitHub token. That token is
kept in their browser and is never sent anywhere except GitHub.

If you have found this page by accident, there is nothing here for you.
